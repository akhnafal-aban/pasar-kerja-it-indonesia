# GOVERNMENT POLICY & PROGRAMS — INDONESIA IT WORKFORCE (FORMAL vs NON-FORMAL)

Research date: 2026-11-09. Scope: state programs/policies employing or absorbing IT workers; formal (salaried/contract/BPJS-registered incl. civil servants) vs non-formal (freelance, gig, informal vendors) distinction enforced throughout. BPS not used (per mission rule; no BPS methodology was needed for any figure below — no BPS figures included).

Labeling: **[REALIZED]** = verified achieved number; **[TARGET/ANNOUNCEMENT]** = policy target only. Every figure carries [SOURCE :: YEAR :: STATUS :: URL :: CONFIDENCE 1-5].

## Program-by-Program Findings

### 1. Digital Talent Scholarship (DTS) — Kominfo → Komdigi (renamed Oct 2024)

ASN), FGA (fresh graduates), TSA (active students), DDE/Thematic, DEA (entrepreneurship), GTA (government apparatus), DLA (leadership), plus Microskill (short self-paced modules — inflates totals; treat separately).

### 6. Formal vs non-formal data

- **BPJS Ketenagakerjaan:** total participants 58.61 juta (Jul 2024; 65.84% active) [Kemnaker satudata/data.go.id :: 2024 :: REALIZED :: https://satudata.kemnaker.go.id/data/kumpulan-data/1913 :: 4]; active target 53.86 juta (2024); Apr 2025: 39.7 juta active (PU + 8.99 juta BPU non-wage/informal + construction) [BPJSTK :: 2024-25 :: REALIZED :: https://www.bpjsketenagakerjaan.go.id/berita/28729/ + /29486/ :: 5]. **No KBLI-based break-out for informatics/tech sector found** → key gap: formal IT employment cannot be derived from BPJS public data as published.
- **Informal IT workforce evidence:** 1000 Startup Digital = 20k freelance vs 4k permanent jobs (only direct ratio found: ~5 informal jobs per formal job in program cohort) [Antara 2023 :: 3]. PROA 2024 intake: 17% unemployed/freelancers and PROA explicitly lists "Freelancer/Pekerja Lepas" as target group [bpsdm.komdigi.go.id :: 2024 :: 4]. World Bank: digital gig work = ladders for urban males, gig digital workers work ~10 hrs more than others [World Bank via Fortune :: 2022 :: 3].
- **Government "pekerja digital" statements:** Menkominfo Budi Arie (Dec 2023): **1.09 juta digital workers = 0.75% of 144 juta labor force** — the only government-overall estimate; methodology never published (BPS-unverified). Note discrepancy vs "3 juta digital talents now" framing used by Komdigi in 2025 [Antara 2025] and vs "1 juta talenta dicetak 2018–2024" [Komdigi :: 2025 :: 2]. These three government figures (1.09M workers / 3M talents / 1M trained) measure different things and are mutually inconsistent in denominator — treat all as low-reliability.
- IT worker associations: no published workforce estimates found from APTIKNAS/MITI in this pass → gap.

## Formal vs Non-Formal Analysis

1. **Government's own programs overwhelmingly operate in the NON-FORMAL/pre-employment space.** DTS (572k cumulative), GNLD (24.6M), 1000 Startup (100k) are training/activation, not employment. Only MSIB/Magang Nasional (subsidized internships, ~250k seats 2025-26) and CPNS form direct formal absorption.
2. **Direct formal government IT employment is tiny and opaque:** only hard number = Kominfo's own 4,215 CPNS 2024 formasi (and even that includes RRI broadcast roles); no national count of IT-role PNS/PPPK exists publicly. The government's formal demand for IT workers runs mostly through procurement (vendors), not payroll.
3. **Where government reported job outcomes, informal dominates:** 1000 Startup Digital: 20,000 freelance vs 4,000 permanent (5:1). If extrapolated across the startup-ecosystem programs government seeds, the informal share of induced IT work is large.
4. **Baseline magnitude:** 1.09M digital workers (official claim, 2023) vs 3M "digital talents" claim (2025) — most of this population is private-sector, and given BPJS shows only ~40M active formal-sector workers total across the whole economy (~27.7M PU), the share of IT workers formally registered is unquantifiable from public data — precisely the gap BPS-style surveys normally fill.
5. **Program-credential inflation risk:** DTS totals mix intense bootcamps (VSGA/PROA, thousands) with self-paced Microskill (503k of 572k claimed graduates). Any workforce-supply model must use core-academy numbers (~69k/yr 2023 level), not headline 572k.

## Methodology Assessment

- **DTS numbers:** internally audited by DPR Puskajiakn — attendance unreconcilable, RAB violations → participant counts are soft-realized. Confidence moderate.
- **MSIB numbers:** official announcements per batch, internally consistent (36,719 + 30,228 + 47,984 + >120k cumulative to batch 5 checks out arithmetically). Best-quality program data found.
- **BPJS:** administrative data (highest quality available) but no sector/KBLI public cut → cannot isolate IT.
- **SPBE:** formal evaluation of 615–621 institutions, published Kepmen — reliable for market-creation context (each institution must staff/contract ICT).
- **Government "digital talent/worker" macro claims** (1.09M / 3M / 9M-need / 12M): policy speech figures, no methodology; use only as bounds, never as data points. This is the same class of distrust the parent study applies to BPS.
