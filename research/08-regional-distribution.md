[StartupBlink Global Startup Ecosystem Index (2026 edition, city pages live) :: 2026 :: index score composite of startups+quality+funding data per 1,000+ cities :: https://www.startupblink.com/startup-ecosystem/jakarta-id :: CONF 4]
- **Jakarta ≈ 55% of all Indonesian job listings on LinkedIn** (snapshot: 11,000+ jobs nationwide vs 6,000+ in "Jakarta Raya"). [LinkedIn jobs pages, live crawl :: Nov 2026 :: live site counts, one-day snapshot, all roles :: https://www.linkedin.com/jobs/jobs-in-indonesia/ + https://id.linkedin.com/jobs/jobs-in-jakarta-raya :: CONF 3]
- **Indonesia needs 9M digital "talents" by 2030 (~600k/yr); universities supply only 100k–200k/yr → 400k–500k/yr gap.** [Kominfo/Komdigi citing World Bank & McKinsey studies, 2015–2030 window :: 2023–2024 :: government restatement of WB/McKinsey demand modelling; supply figure from PT Dikti enrolment data :: https://money.kompas.com/read/2023/06/09/150600726/... + https://bpsdm.komdigi.go.id/... :: CONF 3 (figure is a policy target derived from foreign consultancy research, not a census)]
- **Active tech job postings in Indonesia: 2,717 in Jan 2024, down 8.9% since Oct 2023** (565 new postings that month). [GlobalData job-postings tracker :: 2024 :: aggregates online job postings from major Indonesian job boards :: https://www.globaldata.com/data-insights/macroeconomic/indonesia-technology-related-job-trends-2094630/ :: CONF 3]
- **JobStreet live count: 1,314 "Tech" jobs in Indonesia.** [JobStreet ID tech-jobs page meta :: Nov 2026 :: live site count :: https://id.jobstreet.com/tech-jobs (DDG snippet) :: CONF 3]

## City-by-City Findings
**Jakarta (incl. Jabodetabek)**
- 84.8% of national startup score (StartupBlink, CONF 4 above). All of GoTo, Traveloka + Google/Microsoft/Shopee regional offices in the Golden Triangle; Tokopedia Tower in Kuningan; BSD City "startup city" declared National Strategic Project March 2024. [Digital Districts Jakarta profile :: 2025 :: curated ecosystem audit :: https://www.digitaldistricts.org/ecosystems/indonesia/jakarta :: CONF 3]
- In a live JobStreet feed sample of ~45 newest ICT jobs (fetched 9 Nov 2026), ~70% were located in Greater Jakarta (Jakarta/South/Tangerang/Bekasi), rest in Surabaya, Yogyakarta, Semarang, Batam, Bali, Lamongan. [Own crawl :: 2026 :: non-random single-page sample, indicative only :: https://id.jobstreet.com/id/career-advice/role/software-engineer/salary :: CONF 2]

**Bandung**
- Indonesia's **3rd-largest startup ecosystem by volume**; ITB + Telkom University produce **~8,000 digital-ready graduates/year**; Bandung captures **<3% of national VC deployment by value**; **1/3 of Bandung graduates leave for Jakarta within 18 months**. [Digital Districts Bandung profile :: 2025 :: compiled from university/park/operator records :: https://www.digitaldistricts.org/ecosystems/indonesia/bandung :: CONF 3]
- Global rank #268 in StartupBlink index (declined 7 spots). [StartupBlink :: 2026 :: score index :: https://www.startupblink.com/startup-ecosystem/bandung-id :: CONF 4]
- ITB Innovation Park at Summarecon Bandung: ~40,000 m², soft-opened Dec 2024, 40+ tenants (ICT, AI, transport). [Digital Districts (citing ITB/Sinar Mas) :: 2024 :: operator-reported :: same URL :: CONF 3]

**Yogyakarta (DIY)**
- **610 software companies in DIY province** — Sleman 292 (48%), Kota Yogyakarta 148. [POIData.io :: 2025-26 :: Google Maps POI dataset (scrape of business listings tagged "software company"; includes small firms, excludes unlisted freelancers) :: https://www.poidata.io/report/software-company/indonesia/special-region-of-yogyakarta :: CONF 2 — commercial scraped-data vendor, methodology is POI extraction, not business-registry census]
- Yogyakarta city itself: 61 startups, global rank #494. [StartupBlink :: 2026 :: index :: https://www.startupblink.com/startup-ecosystem/yogyakarta-id :: CONF 4]
- ~84 digital creative companies claimed locally. [Amikom university blog :: undated :: promotional university blog claim, no method :: https://blog.amikom.ac.id/perusahaan-industri-kreatif-digital-di-yogyakarta/ :: CONF 1 — treat as marketing]
- Evidence of outsourced software-house clustering: multiple "top software houses Jogja" lists name GITS Indonesia, Gamatechno, SoftwareSeni (HQ Sydney, dev office Jogja), Black Market (Alexa rank claims), e.g. 10+ in each list. [e.g. https://polluxintegra.co.id/software-house-terbaik-di-yogyakarta/ :: 2023-26 :: no methodology :: CONF 2 for existence of named firms]
- Komdigi (Kominfo) runs its own BLSDM regional talent HQ in Yogyakarta for Central Java/DIY/Bali Digital Talent Scholarship stats. [bpsdm.komdigi.go.id :: 2025 :: government training program :: https://bpsdm.komdigi.go.id/upt/yogyakarta/... :: CONF 3]

**Surabaya**
- 2nd-largest city, 3rd-ranked startup ecosystem; startup base grew ~100% in 2025; startups raised >US$153M to date (named: IDN Times, Komunal, Berachain). ITS Science Techno Park, Markas Surabaya Kominfo digital hub (UK-Indonesia Tech Hub Hatch programmes). [Digital Districts Surabaya profile :: 2025 :: compiled city audit :: https://www.digitaldistricts.org/ecosystems/indonesia/surabaya :: CONF 3]

**Batam**
- Live JobStreet listings show IT roles from electronics manufacturers & industrial companies (Epson Batam programmer staff, Cushman & Wakefield Batam programmer manager — Oct/Nov 2026). [JobStreet live feed :: 2026 :: job ads :: id.jobstreet.com :: CONF 2 (existence evidence, no count)]
- JobStreet salary data: Batam/Bintan/Keplauan Riau have Indonesia's HIGHEST average software-engineer advertised salaries at Rp14jt/mo — above Jakarta (see below).

**Medan, Makassar, Semarang, Malang** — small/undersized ecosystems:
- Digital Districts profiles exist for Medan and Batam (plus Bali, Nusantara) but carry no worker counts; no published IT worker counts found for Medan/Makassar/Semarang/Malang. Makassar & Malang absent from StartupBlink Indonesia top list extracted here. DATA GAP — treated qualitatively only.

## Talent Production by Region
- Universities' computing talent is produced where engineering unis sit — mirroring Java demand geography:
  - West Java/Bandung: ITB + Telkom University = **~8,000 digital-ready grads/yr** [Digital Districts :: 2025 :: CONF 3]
  - Yogyakarta/DIY: Amikom (largest private IT university in Jogja, ~" tens of thousands cumulative alums" claim), UGM [university marketing pages :: CONF 2]
  - Jakarta: Binus (campuses across Greater Jakarta), Universitas Indonesia (Depok), UMN (Tangerang)
  - East Java: ITS Surabaya (STP with 5G Experience Center), UB Malang
  [Locations: university official sites; no PDDikti per-institutiono graduate-by-field extract obtained in this run — cropped SOC/context pages only: PDDikti statistics portal at pddikti.kemdiktisaintek.go.id and data.go.id higher-ed graduate datasets exist for 2023 by institution (data.go.id/dataset/...jumlah-lulusan-perguruan-tinggi-akademik-2023-indonesia) :: CONF 3 portal verified, per-uni IT numbers DATA GAP]
- National supply: 100k–200k digital-talent graduates/yr vs 600k/yr demand [Kompas/Kominfo, 2023, CONF 3 — see headline]

## Remote Work Shift
- **62% of surveyed Indonesian employees prefer hybrid, 21% full-remote, 16% full-office** (Logitech, online survey 16–27 March 2023, n=500 white-collar). [Logitech "Hybrid Work Trend & Insights Indonesia 2023" :: 2023 :: vendor survey, white-collar bias :: https://info.logitech.com/rs/201-WGH-889/images/Logitech-Hybrid-Work-Trend-Insights-Indonesia-2023.pdf :: CONF 4 for method transparency, 2–3 for national representativeness]
- Kalibrr.com structures entire portals by **"Remote Jobs", "Hybrid"**, with per-city job listings (e.g., "New Job opportunity in Jakarta, Remote Working" pages) — remote job-filter infrastructure mainstream by 2026; but Indonesia's tech job ads still overwhelmingly carry a city tag (see JobStreet sample, ~70% tagged to Greater Jakarta). [Kalibrr live site :: 2026 :: platform structure :: https://www.kalibrr.com/home :: CONF 3]
- Workforce flows: **1/3 of Bandung grads relocate to Jakarta within 18 months** (pre-remote-work pattern estimate) [Digital Districts :: 2025 :: CONF 3]; Michael Page mentions migration of hiring outside Jakarta for cost arbitrage (25–45% labor savings outside Jakarta claimed by Aniday, 2026, CONF 3).
- Colliers/Cushman Jakarta office-demand split by tech tenants: NOT FOUND in this run — DATA GAP. (Colliers and Cushman & Wakefield report office absorption; no per-sector tech share figure retrieved via broken search engines.)

## Methodology Assessment
- **Strongest methodology**: JobStreet salary insights — clearly stated method (advertised salaries disaggregated by role & province, updated live, no self-report contamination). StartupBlink composite index — fully published method (indicators weighted traffic/funding/satellite orgs), but measures startup ecosystems, not employee counts.
- **Medium**: Aniday, Michael Page (recruiter benchmark, mostly transparent that data reflects their placements); GlobalData postings tracker; Kominfo 9M figure (heavy policy framing; "digital talent" never defined; derives from McKinsey/WB studies by proxy).
- **Weak/avoid**: PoiData (Map-scrape of listings, inclusion criteria opaque); Amikom blog claims (marketing); Indonesian salary aggregator blogs (kantorku/baodev/whatsthesalary — SEO content mashing GrayscaleContent onto ERI/SalaryExpert numbers, no Indonesian microdata).
- BPS: avoided entirely per method rules. No BPS figure is load-bearing here.
- Search-tool outage: websearch API returned no results on ~10 attempts; all findings gathered via direct fetches & DDG-HTML via r.jina.ai. Totals: 16+ search/fetch actions with extractable numbers.
